# **Система управления студентами**

Простое консольное приложение на Java для управления списком студентов.

**Описание**

Программа предоставляет функциональность для работы с базой данных студентов через консольное меню. Пользователь может добавлять, удалять, просматривать студентов и вычислять статистику.

## Функциональность
**Основные возможности:**

✅ Добавление новых студентов (имя, возраст, оценка)

✅ Удаление студентов из списка

✅ Просмотр всех студентов

✅ Вычисление средней оценки всех студентов

✅ Поиск конкретного студента по номеру или имени

**Особенности:**

- Интуитивно понятное консольное меню
- Защита от некорректного ввода
- Проверка на пустые списки
- Чистый и структурированный вывод информации
